## 线路差价 3.4 倍，到底贵在哪

CN2 GIA-E 20G 年付 $169.99，同配置的 KVM 20G 只要 $49.99/年，差价超过 3 倍。这个差价买的不是配置，是路由。

具体来说，CN2 GIA-E 套餐可选的机房里，洛杉矶 DC6（USCA_6）、DC9（USCA_9）、温哥华 CABC_6、纽约 USNY_8、圣何塞 USCA_SJC5 都是 CN2 GIA + CMIN2 + CUP 三网优化线路——电信走 CN2 GIA，移动走 CMIN2，联通走 CUP。日本大阪 JPOS_1 走软银线路，荷兰 EUNL_9 走联通高级线路。而 KVM 常规套餐的机房走的是普通国际线路，国内访问高峰期丢包和延迟都会明显得多。

一句话判断：你的访客在国内，就为线路花钱；访客在海外或者只是自己折腾，这个差价可以省下来。

另外有些隐性规则会影响实际体验，多数套餐整理文章不会写：

- **最低两档只能季付**。CN2 GIA-E 的 20G 和 40G 档不支持月付，想月付要从 80G 档起。
- **迁移机房流量可能缩水**。KVM 和 CN2 特惠系列可在 8 个机房互迁，但迁到 CN2 线路后月流量按三分之一计算；CN2 GIA-E 的 11 个机房互迁则流量不变。
- **香港、日本套餐不可迁移**，买之前想清楚机房。
- **CPU 有公平使用政策**。比如基础系列的 40GB 档限制为 75% 单核使用率，而 CN2 GIA-E 40G 可以用满 100% 单核再加 50% 第二核——同为“3核”，实际可用算力差一倍。长期跑满 CPU 的网站要留意这一点。
- **这是自管理服务**。系统内的软件安装、配置、故障排查、数据恢复都由你自己负责，官方提供的是基础设施、KiwiVM 控制面板和网络。没有“人工帮你装环境”这种事。

## 建站需要多大配置

比大多数人想的要小。搬瓦工优惠网的站长有多个演示站跑在 1核 512MB 的 VPS 上，网站运行完全正常，资源占用还不算满——而现在搬瓦工最低配已经是 1核 1GB，是这个演示配置的双倍。跑 WordPress 这类 PHP 程序，1GB 内存属于“够用”水平。

有实际流量的网站，2核 2GB 左右一般也够了，内存吃紧时可以开启 Swap 交换分区顶一下。流量再往上涨，搬瓦工支持动态升级配置，补差价即可，不需要重买。

所以买套餐时可以放心从低配起步。比较容易犯的错是反向操作：为了“以后流量大了”直接买 80G 或更高档位，结果 CPU 用不到 10%，一年多花几百美元。真到流量大了再升级，损失只是几分钟的迁移时间。

## 从买完 VPS 到跑起 WordPress 的流程

整个流程五步：买 VPS → 注册域名并解析到 VPS 的 IP → 部署环境 → 装 WordPress → 基础优化。

域名解析完成后，用 ping 工具（比如 ipip.net 的在线 ping）查一下域名是否已经指向你的 VPS IP，确认生效再进入下一步，这一步没生效就装环境是新手最常见的返工原因。

环境部署有三条路，选其中一种即可，不要叠加安装：

1. **LNMP**（Linux + NGINX + MySQL + PHP）。有现成的一键安装包。1GB 内存或更小的方案优先选它，NGINX 对小内存更友好。
2. **LAMP**（Apache 版）。Apache 比较吃内存，适合 2GB 内存以上的套餐。
3. **宝塔面板**。国内团队开发的可视化面板，装好后全程图形界面操作，不想碰命令行的新手选这个。

环境装好后，在面板或一键包里添加站点、建数据库，然后安装 WordPress。装完做四件事：改固定链接（可以加 .html 后缀做伪静态）、改标题和副标题、换主题、按需装缓存和 SEO 插件。想给访问速度再加点分，可以开 BBR 加速——搬瓦工自带的部分系统镜像默认启用 BBR，也可以手动装。

KiwiVM 面板本身对建站者很实用：一键重装系统、快照、自动备份都有，备份服务免费。这意味着升级插件出问题时你有退路。有老站长分享过长期使用体验：网站架在搬瓦工 VPS 上两年多，从美国 CN2 GIA 机房用到香港 CN2 GIA，没遇到过一宕机就是几小时的情况，小波动恢复得也快。

## 常见问题

**搬瓦工只能装 WordPress 吗？**
可以装所有 PHP 程序，Typecho、Z-Blog、Discuz 都没问题。它本质是一台有完全权限的 Linux 服务器，跑 Python、Node.js 也没人拦你。

**1GB 内存够建站吗？**
跑一个普通的 WordPress 站够。有实际运行的 1核 512MB 演示站作参照，1GB 是它的两倍。流量起来后再升级或加 Swap。

**CN2 套餐和 KVM 套餐价格一样，选哪个？**
CN2 特惠 20G 是 1核，KVM 20G 是 2核，同为 $49.99/年；CN2 特惠走 CN2 GT 线路，国内访问稍好于普通线路。自己用选 KVM 的 2 核，给国内访客看且预算紧可以选 CN2。

**买错了机房怎么办？**
KVM 和 CN2 特惠系列可在 8 个机房互迁，CN2 GIA-E 在 11 个机房互迁，注意迁到 CN2 线路流量变三分之一的规则。香港、日本套餐不能迁。

**有退款保障吗？**
搬瓦工对新用户有退款政策，但附有条件和限制，下单前建议先阅读官网的退款条款，别默认“随时可退”。
